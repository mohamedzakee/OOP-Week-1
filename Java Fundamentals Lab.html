Rules to remember

    
    
      
  • Whole numbers are int by default. Values beyond 2,147,483,647 need an L suffix.
    • 
      
  • Decimals are double by default. float f = 123.4; fails; write 123.4f.
    • 
      
  • Underscores go only between digits: never first, last, after 0x/0b, or before L/F.
    • 
      
  • A leading 0 makes a literal octal: 010 is 8, and 09 does not compile.
    • 
    

  







  
Precedence stepper

  
* / % run before + -. Equal precedence runs left to right. Parentheses go first. All arithmetic here uses Java int rules, so division truncates.

  

    

    

    
    
  
    
  
    
    
    Integer division
    7 / 2 is 3, not 3.5. Java drops the fraction (truncates toward zero), so -7 / 2 is -3. Write 7.0 / 2 to get 3.5.
    
    
    Remainder
    a % b takes the sign of a: 7 % 3 is 1, -7 % 3 is -1. A common use: n % 2 == 0 tests for an even number.
